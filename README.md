# Internee.pk Social Media Tracker

A cross-platform mobile app built with React Native (Expo) to track and analyze Internee.pk's social media performance.

## ✨ Features

- Instagram analytics dashboard
- Facebook analytics dashboard
- Follower growth charts (7-day trend)
- Engagement metrics (followers, posts, engagement rate)
- Export complete analytics report as PDF
- Clean bottom tab navigation

## 🛠️ Tech Stack

- **React Native** — Cross-platform mobile framework
- **Expo** — Development and build tooling
- **React Navigation** — Bottom tab navigation
- **react-native-chart-kit** — Data visualization
- **expo-print** & **expo-sharing** — PDF generation and sharing
- **REST API structure** — Data fetching layer in `apiService.js`
